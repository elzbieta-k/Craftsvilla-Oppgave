# Craftsvilla Oppgave

Craftsvilla Oppgave is a static website for a creative workshop business. It showcases available workshops, allows users to book sessions, submit feedback, and view a gallery of previous work.

## Features

- **Home Page (`index.html`)**: Introduction to Craftsvilla, workshop highlights, and business values.
- **Workshop Booking (`bestilling.html`)**: Users can book workshops by filling out a form.
- **Feedback (`tilbakemeldinger.html`)**: Customers can submit feedback and share their experiences.
- **Gallery (`galleri.html`)**: Visual showcase of workshop moments and participant creations.
- **Responsive Design**: Optimized for desktop and mobile devices.
- **Custom Styling**: Uses `style.css` for a unique look and feel.

## Technologies Used

- **HTML5**: Structure and content of all pages (`index.html`, `bestilling.html`, `tilbakemeldinger.html`, `galleri.html`)
- **CSS3**: Custom styling and responsive design (`style.css`)
- **Font Awesome**: Icon library for social media and UI icons
- **Google Fonts**: Custom fonts for typography
- **Unsplash**: Free, high-quality images for gallery and content
- **VS Code Live Server**: Local development and live preview

## File Structure

- `index.html` - Home page
- `bestilling.html` - Workshop booking
- `tilbakemeldinger.html` - Feedback form and testimonials
- `galleri.html` - Gallery of images
- `style.css` - Main stylesheet
- `images/` - Image assets
- `.vscode/settings.json` - VS Code settings for Live Server

Clicking the GitHub pages link automatically starts up the project.
